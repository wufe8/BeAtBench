# BeAtBench — 前端界面设计构思

> 状态：**设计构思稿 v0.1**（只做界面与交互构想，不含实现代码）。
> 配套效果预览：仓库根目录 `beatbench-ui-preview.html`（双击浏览器打开；可切明暗主题、切工作区、折叠 2P、切换左侧面板、点选音符）。
> 落地时机：M2 起填充 GUI 时再据此细化（`doc/04` 里程碑：M2 = 元信息表单 + 文件绑定管理 + 时间轴 + 工作区切换外壳）。

## 0. 一句话定位

BeAtBench 的 GUI 是一个**高密度、键盘优先的桌面谱面编辑器**（Qt Widgets + QPainter 自绘视口）。
本稿只回答两件事：① 界面长什么样（布局 / 区域 / 交互）；② 界面怎么对接 core——**「命令即接口」**（对齐稿 02 §6.1）。
术语口径见 §10，代码框架抽象见 §11。

## 1. 设计原则

1. **命令即接口**：GUI = 交互式命令执行器。每个编辑动作 = 一条 core 命令：`apply → 入 undo 栈 → 视图刷新`。界面层不直接改 `Chart`。
2. **会话状态不入 undo**：选择集、视口、播放头、面板布局是会话状态，不产生命令（对齐稿 01 §5）。
3. **高密度 + 键盘优先**：面向谱师长时编辑；控件紧凑，主操作都有键位（LR2 布局）。
4. **深色默认**：长时间使用默认深色，可切浅色；HiDPI 优先。
5. **渲染分级**：主视口自绘，收敛在 `IChartView` 接口后（02 §5.2）；本稿不涉及渲染实现。

## 2. 顶层信息架构

- 两个**平级工作区**（Workspace）：`编辑` | `切音`（M2 只搭外壳，切音 Phase C/M6 填充）。
- `编辑` = 时间轴 + 轨道视图（本稿主体）；`切音` = 波形切片工作台。
- 编辑工作区内再分三层：**左 Dock（资源/诊断/预览）· 中央视口（时间轴）· 右 Dock（属性）**。

## 4. 区域设计

### 4.1 顶部工具条（两排）
- **主工具条**：工作区切换（编辑 | 切音）、snap（1/1 … 1/64、free）、量化、网格、缩放、试听/停止（Phase B 前置灰）、模式（`ChartMode`）、滚动方向。
- **编辑工具条（第二排）**：工具选择（选择 / 放置 note / LN / 地雷 / 平移 / 缩放，建议占位键位 `V N L M H Z`）+ 当前采样 + 快捷键提示（`1-7` 放键、`皿`、`F1-F7` 备用、`Del` 删除、`Esc` 取消）。

### 4.2 中央视口（时间轴，竖向）
- **小节标尺**（左）：竖排 `Event.measure` 号，与水平小节网格线对齐。
- **滚动方向（可切换）**：默认「顶部=高小节、底部=低小节」（贴合 note 自上而下落的游玩直觉）；工具条可切换为「顶部=低小节」。对齐 iBMSC 的滚动方向选项。
- **轨道列**：`Lane` 抽象（`player`/`kind`/`index`），**不出现 BMS 通道号**（通道映射是 codec 层职责）。列：皿 / 1–7 / BGM / 2P（可折叠）。
- **note 落位**：`Event<Note>` 按 `(measure, pos)`；普通 note 短条、LN 头尾 + 填充、地雷异形。
- **BGM 波形铺底**：Phase B 后 `#WAVxx` 波形对齐铺底。
- **秒标尺**（右）：绝对时间，变速非线性（`TimingEngine`），BPM/STOP 处刻度加密。
- **播放头 / 网格 / 框选**：会话状态。

### 4.3 左 Dock（标签页）
- **采样管理器**：定义表 `Chart.samples`（WAV/BMP/BPM/STOP 分命名空间），含缺失文件告警（对应 CLI `check`）。
- **lint 报告**：解析诊断（`Severity` Error/Warn/Info），点击跳转到时间轴位置。
- **BGA 预览**：`bga_events` 图像 + 图层/不透明度（依赖图像解码，后置）。
- **元信息**：`Chart.meta` 表单（`#TITLE`/`#ARTIST`/`#BPM`/`#PLAYER`/`#PLAYLEVEL`…）。

### 4.4 右 Dock（属性）
- 选中对象属性：`Lane`、`(measure, pos)`、`SampleRef`、`NoteKind`、LN 配对。
- 动作按钮 = 命令（移动 / 删除 / 改采样 / 重连 LN）。

### 4.5 状态栏
- 模式、小节范围、note 数、缩放、当前命令提示。

## 5. 关键交互

- **键盘**：LR2 布局（`1-7` + 皿键 + 备用 `F1-F7`），编辑态抑制 IME（01 §6）；工具键占位 `V N L M H Z`（选择 / 放置 / LN / 地雷 / 平移 / 缩放），`Del` 删除、`Esc` 取消。
- **鼠标**：点放（= `note.put`）；框选（会话状态）；拖动（= `note.move`，`merge_with` 合并为一步 undo）；滚轮微调。
- **snap / 量化**：工具条切换，只作用于落点换算，不改变数据精度。

## 6. 界面 ↔ core 命令映射（命令即接口）

| 界面区域 | 用户动作 | 建议命令名 | core 落点 | 备注 |
|---|---|---|---|---|
| 视口点放 | 放置 note | `note.put` | `Chart.notes` | apply/invert |
| 视口拖动 | 移动 note | `note.move` | `Chart.notes` | `merge_with` 合并拖动 |
| 视口删除 | 删除 note | `note.delete` | `Chart.notes` | |
| 视口 LN | 连接/断开头尾 | `ln.link` / `ln.unlink` | `Note.ln_pair` | 维护互指 |
| 属性面板 | 改采样 | `note.paint` | `Note.sample` | |
| 时间轴 | 改 BPM/STOP/节拍 | `bpm.change` / `stop.change` / `measure.change` | `bpm_events`/`stop_events`/`measure_events` | 触发秒标尺重算 |
| 元信息表单 | 改头部字段 | `meta.edit` | `Chart.meta` | |
| 采样管理器 | 绑定/导入采样 | `sample.bind` / `sample.import` | `Chart.samples` | 文件绑定 |
| BGA 面板 | 改 BGA | `bga.change` | `Chart.bga_events` | |
| 切音工作台 | 切片 | `slice.*`（M6） | 待定 | 预留 |
| 选择集/视口/播放头 | — | 无命令 | 会话状态 | 不入 undo |

> 命令名沿用 `Command::name()` 的稳定字符串约定（如 `note.put` / `bpm.change`，见 `core/.../commands/Command.hpp`）。
> CLI 与 GUI 共用同一套命令；`check`/`info` 是只读解析，不产生 undo。

## 7. 设计语言（token）

- 深色默认：`--bg #0b0d10 · --surface #12151a · --border #262b33 · --text #e6e9ee`
- 主色 `--primary #6366f1`（靛蓝）、强调 `--accent #22d3ee`（青）、语义色 success/warn/danger
- note 着色：按键轨靛蓝、皿轨青、地雷红、LN 尾半透明
- 字体：系统无衬线 + 等宽（标尺/数值/代码）
- 密度：紧凑；完整 token 见 `beatbench-ui-preview.html` 顶部 `:root`

## 10. 术语与命名约定（沟通口径）

> 目的：避免「页面 / 界面 / 视图」混用造成歧义。桌面应用**不用「页面」**，统一如下。

| 中文叫法（统一用） | 英文 / 代码标识 | 含义 |
|---|---|---|
| 主窗口 | `MainWindow` | 应用唯一顶层窗口，组装一切 |
| 工作区 | `Workspace` / `EditWorkspace` / `SliceWorkspace` | 顶层模式：编辑 / 切音（平级切换） |
| 视图 | `View` / `ChartView` / `WaveformView` | 视口内自绘内容区 |
| 主视口 | `ChartView`（接口 `IChartView`） | 时间轴 + 轨道自绘区 |
| 面板 | `Panel`（`SamplePanel` 等） | 左右 Dock 里可切换的功能块 |
| Dock | 左 Dock / 右 Dock | 面板容器（可拖拽与否待拍板） |
| 工具条 | `Toolbar`（`MainToolBar` / `EditToolBar`） | 顶部两排按钮组 |
| 状态栏 | `StatusBar` | 底部信息条 |
| 标尺 | `Ruler`（`MeasureRuler` / `SecondRuler`） | 小节标尺 / 秒标尺 |
| 轨道 | `Lane`（core 已有） | 皿 / 1-7 / BGM / 2P 列 |
| 时间轴 | Timeline | 竖向时间轴（= 主视口内容） |
| 对话框 | `*Dialog` | 设置 / 导入等弹窗 |

约定：
- 中文沟通统一：主窗口 / 工作区（编辑·切音）/ 视口 / 面板 / 工具条 / 状态栏 / 对话框。
- 「编辑工作区」= 时间轴 + 轨道 + 双工具条；「切音工作区」= 波形切片。
- 面板名直接叫「采样面板 / lint 面板 / BGA 面板 / 元信息面板 / 属性面板」。

## 11. 代码框架抽象（app 层）

> 仅做**结构与命名抽象**，不含实现；M2 落地再细化。GUI 全部收敛到「命令即接口」：界面只翻译手势 → core 命令 → 刷新。

### 11.1 目录 / 模块布局（app/）

```
app/
├─ main.cpp                   # QApplication 入口
├─ MainWindow.{h,cpp}         # 主窗口：组装菜单/工具条/工作区/Dock/状态栏
├─ workspace/
│  ├─ Workspace.h             # 工作区抽象接口（activate/deactivate/工具条集）
│  ├─ EditWorkspace.{h,cpp}   # 编辑工作区 = 时间轴 + 轨道 + 双工具条
│  └─ SliceWorkspace.{h,cpp}  # 切音工作区（Phase C/M6，占位）
├─ views/
│  ├─ IChartView.h            # 主视口抽象（QPainter 起步，瓶颈后可换 QOpenGLWidget）
│  ├─ ChartView.{h,cpp}       # 竖向时间轴自绘（note/LN/地雷/网格/播放头）
│  ├─ MeasureRuler.{h,cpp}    # 小节标尺
│  ├─ SecondRuler.{h,cpp}     # 秒标尺（TimingEngine 驱动，非线性）
│  └─ WaveformView.{h,cpp}    # BGM 波形铺底（Phase B）
├─ panels/
│  ├─ SamplePanel.{h,cpp}     # 采样管理器（Chart.samples）
│  ├─ LintPanel.{h,cpp}       # lint 报告（Diagnostic 列表）
│  ├─ BgaPanel.{h,cpp}        # BGA 预览
│  ├─ MetaPanel.{h,cpp}       # 元信息表单（Chart.meta）
│  └─ PropertyPanel.{h,cpp}   # 属性面板（选中对象 → 命令）
├─ toolbars/
│  ├─ MainToolBar.{h,cpp}     # 主工具条（工作区/snap/量化/网格/缩放/试听/模式/滚动方向）
│  └─ EditToolBar.{h,cpp}     # 编辑工具条（工具选择/当前采样/快捷键提示）
├─ input/
│  ├─ KeyMap.{h,cpp}          # LR2 键位表（默认/自定义）+ 编辑态 IME 抑制
│  └─ InputHandler.{h,cpp}    # 鼠标手势（点放/框选/拖动/滚轮）→ 命令
├─ state/
│  ├─ DocumentState.{h,cpp}   # Chart + UndoStack（命令栈：apply/invert/merge）
│  ├─ SessionState.{h,cpp}    # 选择集/视口/播放头/面板布局（不入 undo）
│  └─ CommandExecutor.{h,cpp} # GUI 侧命令执行器：执行 → undo 栈 → 视图刷新
└─ style/                     # （可选）设计 token 常量（色板/间距），与 preview 对齐
```

### 11.2 关键接线（命令即接口）

1. 用户手势 → `InputHandler` 生成 core 命令（`note.put` / `note.move` / …）。
2. `CommandExecutor` 执行：`cmd.apply(chart)` → 成功入 undo 栈 → 发刷新信号。
3. `ChartView` 与各面板订阅刷新信号，从 `DocumentState` / `Chart` 重绘。
4. 会话状态（选择集/视口/播放头/面板布局）走 `SessionState`，不进 undo。

### 11.3 与 core 的边界

- app 不直接改 `Chart`，只经命令；core 维持零 Qt 依赖（现有约束不变）。
- 模式查表：core `ChartMode` → app 层按 `mode_id` 选视图布局与默认键位。
