# 路线图（已拍板方向）

> 本文只记录已拍板的方向与顺序，不记录进度、完成度、当前状态、日期或排期。
> 实现进度见 git 历史与 Release 说明；过程与验收记录不进入公开文档。
> 仅在方向或顺序被重新拍板时更新本文；某项开始、完成或延期不更新本文。

## 方向

| 阶段 | 已拍板方向 |
|---|---|
| M7 项目化工作流 | 单曲文件夹即项目；独立文档与统一保存；资源引用与缺失检查、多谱绑定更新；A/B 对照（B 只读）；本地谱面快照；后续方向为 B 编辑与同文档跨窗格移动 |
| M8 边界与协议 | SliceWorkspace 与 bridge 边界拆分；CSV 时标导出；MIDI tempo 接入；codec 能力声明与命令能力协商 |
| M9 格式与模型 | bmson codec 原型；`#RANDOM/#IF` 结构化 AST 与可靠往返 |
| M10+ 生态与体验 | i18n；可选试玩判定；外部预览适配器；Lua/脚本接口；L2 布局皮肤 |

## 明确非目标

- 两谱同时出声的混合播放。
- 程序内资源复制或导入；资源文件操作交给系统文件管理器。
- 专有项目或工作区文件格式。
- 完整试玩判定作为主线（只做可选或外置）。
- 真正 LNTYPE2（MGQ）兼容。

## 更新规则

- 新增、删除或调整方向与顺序 = 一次拍板，更新本文。
- 某项开始、完成、延期或更换实现方式，不更新本文。
- 里程碑内的交互细节、验收标准与未决问题不进入本文。
