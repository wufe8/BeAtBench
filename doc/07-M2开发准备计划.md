## 2. 构建命令（已实测）

```powershell
# 全新配置 + 构建 GUI（tests OFF，避免联网拉 GoogleTest）
cmake -S . -B build-gui -G Ninja -DCMAKE_BUILD_TYPE=Debug `
  -DCMAKE_PREFIX_PATH="G:/Qt/6.11.1/mingw_64" `
  -DCMAKE_CXX_COMPILER="G:/Qt/Tools/mingw1310_64/bin/g++.exe" `
  -DCMAKE_MAKE_PROGRAM="G:/Qt/Tools/Ninja/ninja.exe" `
  -DBEATBENCH_BUILD_TESTS=OFF
cmake --build build-gui --target beatbench
# 产物：build-gui/app/beatbench.exe；冒烟：运行 3 秒应存活（已实测）

# 打包部署（发布时）
& "G:\Qt\6.11.1\mingw_64\bin\windeployqt.exe" build-gui\app\beatbench.exe

# CLI + 测试回归仍用原 MSVC 目录（如需重建）
cmake -S . -B build -DBEATBENCH_BUILD_TESTS=ON
cmake --build build --config Debug --parallel
ctest --test-dir build -C Debug --output-on-failure
```

- `build-gui/` 已加入 `.gitignore`（2026-08），永不提交；
- GUI 开发期间 `BEATBENCH_BUILD_TESTS=OFF`；core 逻辑回归交给 MSVC `build/`。
  若网络可用，也可在 build-gui 开 tests（GoogleTest 支持 MinGW），但非必需；
- **M2 开工第一件事**：`app/CMakeLists.txt` 改 `find_package(Qt6 COMPONENTS Quick QuickControls2)` +
  `QQmlApplicationEngine` 入口（doc/08 §6 待办）；
- MinGW 的 `-Wall` 比 MSVC `/W4` 更严，core 暴露 1 处既有警告：
  `core/src/bms/bms_parser.cpp:337` 未使用变量 `data`——顺手清理（M2 首个小 commit 可带上）。

## 3. M2 起步路线（对齐 doc/04 §6「▶ M2 起步建议」）

**节奏纪律：壳与纯视觉可用假数据占位；每个功能第一版必须走真命令全链路
（对话框 → `global_registry().dispatch()` → 模型 → 视图），不允许「整块先假、以后统一换真」。**

1. **Workspace 外壳（QML 壳）**（假数据占位视觉）
   - `QQmlApplicationEngine` 入口 + 根 QML（`Main.qml`）：菜单/工具条/左中右三栏/状态栏骨架，
     对照 `beatbench-ui-preview.html` 直译（**QML 声明式 ↔ HTML 声明式，别带 C++ Widgets 习惯**）；
   - 工作区切换（编辑|切音）即刻可点；外壳即未来皮肤系统的「内置默认皮肤」骨架（doc/08 §3.4）；
   - 布局容器用 QML 原生（Row/Column/SplitView/Dock 需自建或 QML 惯用布局），**不用 QDockWidget**。
2. **core↔QML 桥接层（app/bridge）**：`CommandDispatcher`（QObject 包装 `dispatch()`）+
   `ChartModel`（QAbstractListModel）+ `TimingEngine` 包装（doc/08 §4）——第一条真链路的前置。
3. **第一条真链路**：打开谱面（文件对话框 → `dispatch(info)`）→ QML 元信息表单
   （TITLE/ARTIST/BPM/PLAYER…）——验证「GUI = 协议客户端」全栈。
4. **文件绑定 + lint**：采样面板（`Chart.samples` 四类定义表，缺失告警）+
   lint 面板（`check` 的 lint 数据：missing_wav 高亮、点击跳转）。
5. **时间轴视图**（最难点）：`QQuickPaintedItem` 子类（QPainter 自绘竖向时间轴，doc/08 §2 桥接路线）
   + 小节标尺（BPM 分段/网格、轨道列 皿/1-7/BGM/2P 折叠位、note 按 (measure,pos) 落位），
   数据源 = **TimingEngine 真数据**。秒标尺后置 Phase B。
6. **收尾**：回归 + 提交（Conventional Commits；SPDX 头；只提交 doc/ 与源码）。

## 5. 风险清单

1. **两套构建目录并存**（MSVC build/ 回归 + MinGW build-gui/ GUI）：提交前确认产物不混淆；
2. GoogleTest FetchContent 需联网（build/_deps 已有缓存，MSVC 侧无碍）；
3. 预览 HTML 是**设计参照不是移植源码**——QML 是声明式文本，对照直译组件树/属性，别把 C++ Widgets 习惯带进 QML；
4. MinGW 警告比 MSVC 多（§2 已列一处），新增代码尽量零警告；
5. **QML 双语言纪律**（doc/08 §2）：逻辑放 C++（bridge），QML 只管表现，JS 别写散——写进 code review 清单；
6. QML 首次加载/场景图初始化略慢、体积略大：可接受，发布时 qmlsc 预编译缓解（doc/08 §2）。
