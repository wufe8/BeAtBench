# BeAtBench — 前端界面设计构思

> 已拍板的页面结构、职责与术语。实现以 QML、桥层代码及其头注释为准。

## 一句话定位

GUI 用 Qt Quick / QML 组织工作区；界面不自行修改谱面模型。设计栈见 [皮肤系统](skin-system.md)，操作信封见 [命令协议](command-protocol.md)。

## 一、设计原则

- 页面式工作区：固定菜单与状态栏，页面切换只改变工作区和工具条，不隐式重载谱面。
- 选择、视口、播放头和布局属于会话状态，不进谱面撤销历史；模块硬规则见 [app/AGENTS.md](../app/AGENTS.md)。
- 深色为默认；外观可覆写，页面和文档职责独立于皮肤。

## 二、顶层信息架构：页面（Pages）

底部页面条按当前顺序提供四项：

| 页面 | 职责 |
|---|---|
| 项目 | 单曲文件夹的谱面、资源、已打开文档与批量操作，见 [项目工作流](project-workflow.md) |
| 编辑 | 谱面内容、文件绑定、诊断与试听 |
| 切音 | 导入参考音频或 MIDI、切分、导出及铺入谱面，见 [核心模型](core-model.md) 三、 |
| 测试 | 试玩 / 预览占位，不表示完整试玩已提供 |

## 三、主窗口布局（页面式）

全局菜单、页面工具条及内容区、底部页面条和状态栏相互分离；编辑页内容为左 Dock、中央视口、右 Dock。实际装配见 [主窗口](../app/qml/Main.qml) 与 [页面条](../app/qml/components/PageSwitcher.qml)。

## 四、区域设计

### 1. 固定 chrome（跨页面）

菜单和状态栏为全局区域，页面条位于底部。调整这些区域的位置属于 L2 设计目标，不是现行设置项。

### 2. 页面工具条（内容随页面变化）

页面工具条提供当前工作区操作；编辑工具条承载编辑工具与当前采样，切音使用独立工作台工具条。

### 3. 编辑页内容（默认三栏模板 = 空模板的默认布局）

- 左 Dock：采样、诊断、BGA 和元信息；采样面板具体交互见 [SampleListModel](../app/bridge/SampleListModel.hpp)。
- 中央视口：竖向谱面时间轴、轨道、标尺与波形；BGM 可展开为源子通道列，展开或收起不改谱面。
- 右 Dock：选中对象的属性。A/B 分栏时的编辑、属性和播放归属见 [项目工作流](project-workflow.md) §4.3 和 §4.5。

### 4. 切音页 / 测试页

两页的能力范围见二、；切音的目标解析和写出边界见 [项目工作流](project-workflow.md) §9.3。

## 五、关键交互（不变）

吸附调整交互落点，不改变谱面位置的存储精度。拖动预览不是文档编辑；提交的实际编辑才进入撤销历史。快捷键与动作见 [动作注册表](action-registry.md)，编辑约束见 [核心模型](core-model.md) 四、。

## 六、界面 ↔ core 命令边界

界面动作与文档命令不是一一对应。命令形状以 [命令协议](command-protocol.md) 三、与命令代码为准；长音的源身份、连接与放置规则见 [BMS 格式笔记](<bms-format-notes.md#长音>)。

## 七、设计语言（token）

颜色、字体和密度由主题 token 表达，不在本文复制数值。覆写范围和默认值的权威见 [皮肤系统](skin-system.md) 三、5.。

## 八、页面与皮肤边界（mod 友好性）

页面集由应用定义，内置皮肤是完整产品界面，也是现行主题的参考。区域或组件覆写属于 L3 设计目标，不声明当前 QML 组件接口是第三方稳定 API。分层边界以 [皮肤系统](skin-system.md) 三、为准。

## 九、代码落点

[QML](../app/qml/) 负责界面表现；桥接及交互实现以 [C++ 桥层](../app/bridge/) 的代码和头注释为准。

## 十、术语与命名约定（QML）

“页面”指顶层任务模式；“页面条”用于切换这些模式；“Dock”指侧边面板容器；“面板”指容器中的功能组件；“视口”指中央谱面绘制和输入区域；“标尺”显示位置或时间；“轨道”是谱面对象的逻辑归属，轨道列是其视图呈现。使用这些桌面应用术语，不混用 Web 导航概念。
