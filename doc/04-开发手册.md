# BeAtBench 开发手册（新会话引导）

> **给新会话/小模型的引导文档**：读完本文件即可开工，无需重读全部设计文档。
> 文档地图（按任务查该读哪份、doc/local 分布约定）见 [doc/README.md](./README.md)。
> 权威设计细节见 [02-对齐稿](./02-C++Qt方案对比与切音工作流.md)；本文件与其冲突时以 02 为准（并请顺手更新本文件）。

## 1. 项目一句话

BMS 谱面编辑器（替代 BMSE/iBMSC）。C++20 + Qt 6（**GUI 层 Qt Quick/QML**，core 零 Qt 依赖）+ CMake；Phase B 引入 PortAudio。许可 **GPL-3.0**（每个新文件加 SPDX 头 `// SPDX-License-Identifier: GPL-3.0-only`）。GUI 栈决策见 **doc/08**（2026-08 定：QML + 分层皮肤系统）。

## 2. 已定决策速查

- 平台：Windows 优先；架构保持跨平台（不引入 Win 专有 API 进 core）。
- 格式：**v1 只做 .bms 文本**（零第三方依赖手写解析）；bmson 仅架构预留（codec 接口先立）。
- v1 范围：谱面信息 + 文件绑定 + note 摆放（含 LN/地雷/变速编辑/多模式视图/undo/自动保存）。**不含**试玩与实时播放（Phase B）、切音工作台（Phase C）。
- 优先级：基础功能 → 编辑期间随时播放（M5）→ 切音工作台（M6）；试玩模式=可选/外置。
- 核心模型**格式无关**：无通道号、无 36 进制 ID、无 1296 上限——这些全是 bms codec 层的映射（02 §4）。
- 调用架构：**命令对象 = 唯一操作面**（core/commands），GUI/CLI/未来 Lua 三种执行器共用（02 §6.1）。
- GUI 栈：**Qt Quick/QML + 分层皮肤系统**（2026-08 定，doc/08）；core 零 Qt 依赖不变。
- 采样：wav/ogg，44100/48000Hz 优先（Phase B 才需要解码）。

## 3. 仓库布局

```
core/include/beatbench/core/   模型（Rational/Lane/SampleRef/ChartMode/Event/Payloads/Chart）
core/include/.../core/bms/     BMS 文本 codec 接口（M1 实现）

tests/ GoogleTest（Rational/JSON/命令/事件化/时序，见 §6）
doc/   设计文档；local/ 为私人笔记（gitignore，勿提交）
```

## 4. 构建与测试

工具链要求：**C++20**——MSVC ≥ 19.29（VS 2022+）或 GCC ≥ 10 / Clang ≥ 12。
⚠️ Git for Windows 自带的 g++ 6.3 太老（不支持 C++20），不可用。本机已验证可用：MSVC BuildTools（VS 18）。

```powershell
# CLI + 测试（MSVC 默认生成器；测试需联网拉 GoogleTest）
cmake -S . -B build -DBEATBENCH_BUILD_TESTS=ON
cmake --build build --config Debug --parallel
ctest --test-dir build -C Debug --output-on-failure

# 只编 CLI（无网可用）
cmake -S . -B build -DBEATBENCH_BUILD_TESTS=OFF
cmake --build build --config Debug --target beatbench-cli

# GUI：Qt Quick/QML，需 Qt 6 + Quick/QuickControls2（本机 6.11.1 MinGW 实测命令见 doc/07 §2）
```

注意事项：
- 源文件一律 UTF-8 保存；CMake 已为 MSVC 加 `/utf-8`，不要移除；
- MinGW 路线用 MinGW-w64（不是 Git 自带 g++），生成器 `-G "MinGW Makefiles"`。

## 5. 代码约定

- 文件 snake_case（`bms_codec.cpp`）、类型 PascalCase（`TimingEngine`）、命名空间 `beatbench::<模块>`。
- 注释用中文（面向本项目维护者与后续小模型）；SPDX 头必须。
- core 零 Qt/音频依赖；当前 header-only，需要实现时转 STATIC 库。
- 事件容器保持按 (measure, pos) 升序；Note.ln_pair 存容器下标（编辑后需重算，M2 注意）。
- 提交信息：Conventional Commits 简版（`feat:`/`fix:`/`docs:`/`refactor:`/`test:`）。
- **只提交 doc/ 与源码；local/、build/ 永不上传。**
