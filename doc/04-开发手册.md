> 权威设计细节见 [02-对齐稿](./02-C++Qt方案对比与切音工作流.md)；本文件与其冲突时以 02 为准（并请顺手更新本文件）。

## 1. 项目一句话

BMS 谱面编辑器（替代 BMSE/iBMSC）。C++20 + Qt 6（**GUI 层 Qt Quick/QML**，core 零 Qt 依赖）+ CMake；Phase B 引入 PortAudio。许可 **GPL-3.0**（每个新文件加 SPDX 头 `// SPDX-License-Identifier: GPL-3.0-only`）。GUI 栈决策见 **doc/08**（2026-08 定：QML + 分层皮肤系统）。

## 2. 已定决策速查

- 平台：Windows 优先；架构保持跨平台（不引入 Win 专有 API 进 core）。
- 格式：**v1 只做 .bms 文本**（零第三方依赖手写解析）；bmson 仅架构预留（codec 接口先立）。
- v1 范围：谱面信息 + 文件绑定 + note 摆放（含 LN/地雷/变速编辑/多模式视图/undo/自动保存）。**不含**试玩与实时播放（Phase B）、切音工作台（Phase C）。
- 优先级：基础功能 → 编辑期间随时播放（M5）→ 切音工作台（M6）；试玩模式=可选/外置。
- 核心模型**格式无关**：无通道号、无 36 进制 ID、无 1296 上限——这些全是 bms codec 层的映射（02 §4）。
- 调用架构：**命令对象 = 唯一操作面**（core/commands），GUI/CLI/未来 Lua 三种执行器共用（02 §6.1）。
- GUI 栈：**Qt Quick/QML + 分层皮肤系统**（2026-08 定，doc/08）；core 零 Qt 依赖不变。
- 采样：wav/ogg，44100/48000Hz 优先（Phase B 才需要解码）。

## 4. 构建与测试

工具链要求：**C++20**——MSVC ≥ 19.29（VS 2022+）或 GCC ≥ 10 / Clang ≥ 12。
⚠️ Git for Windows 自带的 g++ 6.3 太老（不支持 C++20），不可用。本机已验证可用：MSVC BuildTools（VS 18）。

```powershell
# CLI + 测试（MSVC 默认生成器；测试需联网拉 GoogleTest）
cmake -S . -B build -DBEATBENCH_BUILD_TESTS=ON
cmake --build build --config Debug --parallel
ctest --test-dir build -C Debug --output-on-failure

# 只编 CLI（无网可用）
cmake -S . -B build -DBEATBENCH_BUILD_TESTS=OFF
cmake --build build --config Debug --target beatbench-cli

# GUI：Qt Quick/QML，需 Qt 6 + Quick/QuickControls2（本机 6.11.1 MinGW 实测命令见 doc/07 §2）
```

注意：
- **测试耗时分档**（2026-08）：完整回归 ≈ 2.5~5 分钟——大头 = `TimingRealCharts`（358 谱面逐事件
  时序正逆算，固定 ~58s）+ `BmsRealCharts`（359 谱面文本往返，磁盘/杀软扫描影响波动 176~270s）。
  日常开发用**快速回归**：`BB_SKIP_REAL=1 ./build/tests/Debug/beatbench_tests.exe`（跳过两个
  真实谱面集，<1s）；提交前跑完整回归；`BB_ONLY=<子串>` 只跑匹配文件名的样本（现象定位用）。
- 注意事项：
- 源文件一律 UTF-8 保存；CMake 已为 MSVC 加 `/utf-8`，不要移除；
- MinGW 路线用 MinGW-w64（不是 Git 自带 g++），生成器 `-G "MinGW Makefiles"`。

## 5. 代码约定

- 文件 snake_case（`bms_codec.cpp`）、类型 PascalCase（`TimingEngine`）、命名空间 `beatbench::<模块>`。
- 注释用中文（面向本项目维护者与后续小模型）；SPDX 头必须。
- core 零 Qt/音频依赖；当前 header-only，需要实现时转 STATIC 库。
- 事件容器保持按 (measure, pos) 升序；Note.ln_pair 存容器下标（编辑后需重算，M2 注意）。
- 提交信息：Conventional Commits 简版（`feat:`/`fix:`/`docs:`/`refactor:`/`test:`）。
- **只提交 doc/ 与源码；local/、build/ 永不上传。**
- ⚠️ **QML 字符串格式化只用链式单参 `.arg()`**（`qsTr("…%1…%2").arg(a).arg(b)`）：
  multi-arg `.arg(a, b)` 在 QML 引擎抛 `String.arg(): Invalid arguments` **并中止当前 JS 函数**
  （2026-08 实测：异常静默中止 openChart()，后续 loadFromInfo 未执行 → 采样面板空列表）。
- ⚠️ **互斥单选组用「外部激活态」而非控件 `checkable` 自翻**：checkable 点击会翻转 checked
  并断开绑定（多选残留）。统一模式 = 状态放 window/model 单值（`editorTool`/`group`），
  按钮 `active: 状态 === id` + `onClicked` 赋状态（见 BbToolButton.active、doc/05 §4.3）。
- QML Repeater delegate 不写 `required property index`（会屏蔽隐式 modelData/index 注入）。
- ⚠️ **AUTOMOC 对 target sources 的自动 include 扫描不可靠**：带 Q_OBJECT 的 app 头文件
  （bridge/*.hpp）必须**显式列入 `add_executable(..., bridge/X.hpp)`**，否则 moc 不生成、
  链接报 vtable undefined（2026-08 实测）。Flickable 无 `onWheel` 信号——横向滚动用
  `WheelHandler`（QtQuick）；Flickable 无隐式高度——布局内设 `implicitHeight`/`Layout.preferredHeight`。

### ⚠️ 防回退纪律（历次交接与实测沉淀，**勿改回**）

> 2026-09 清理 local/doc/handoff-*.md 后，把「容易改错/曾踩坑必记住」的结论收敛到本手册。
> 每条都来自真实踩坑（括号里是场景），改动相关代码前先读。

- **`find_note` 保持 measure 段线性扫描**，**勿改回 (measure,pos) 二分**——parser 按通道行序
  push，同 measure 内 pos **非升序**；二分曾导致 Del/移动对非首 note 静默 No-op（2026-09）。
- **`ln_pair` 是「文件数据 → 解析 → 呈现连接」的派生过程**（`rebuild_ln_pairs` 自下而上推导，
  每次文档变更后统一重推），**不是编辑真相源**——编辑命令不主动维护/自动重连/成对随动（会串 note），
  只按伙伴**值**重定位配对；跨通道移动后 rebuild 天然断开、同通道保持（用户原则）。
  `Note.ln_channel`（bool，来自 51-69/61-69）是解析时静态标记，**移动后必须更新**（换轨置 false）。
  **LNTYPE 2（#LNOBJ）**：`rebuild_ln_pairs`（2026-09）已支持——`chart.meta["LNTYPE"]=="2"` 时
  头尾同在普通通道（11-29），值 == `#LNOBJ`（缺省 ZZ）的 note = 尾，头 = 同 lane 最近未配对前件
  （head-stack 式，与 parser 一致）；`Note.ln_channel` 在这些 note 上为 false。LNTYPE 1 路径不变。
- **`bgm_line` 必须前后端透传**（放置/移动/删除都带，否则落到 bgm1）；字段名**统一下划线
  `bgm_line`**——C++ 曾输出驼峰 `bgmLine` 而 core 读下划线 `bgm_line`，导致 bgm>1 子轨
  note 被 `find_note` 判 0、静默无操作（2026-09）。`Bpm.ch08` / `Bpm.ref_id` / `Stop.ref_id` /
  `Note.bgm_line` / `Note.ln_channel` 都是**辅助字段，不参与 `operator==`**。
- **ch08 BPM 通道保真**：`Bpm.ch08`（来自 ch08 `#BPMxx` 引用）→ writer **恒写 ch08**；ch03 仅写
  **整数 1..255 的十六进制**；其余（非整数/>255/负）才写 ch08 引用。**勿一律写 ch03 定宽引用**
  （曾把 `#00108:00000002` 改写成 `#00103` → 标准播放器读成 2 BPM，格式破坏）。
- **BMS 通道映射决定可表示性**：`bms_channel_for_mode(mode, lane, ln=true)` 为空 = 该轨不可放
  LN（如 BMS ch01 BGM 无 LN 通道）——前端/协议按此拦截，不产生脏数据；writer 对 BGM 忽略
  ln 标记恒写 ch01（防丢兜底）。
- **LN 移动语义（最终）**：`move_ln_pair=false`（缺省）= LN 当单 note、移动只动一个、配对由
  rebuild 自然延续/断链（lint 提示）；`=true` = 头尾成对移动（相对位置不变、互指保持）。
- **`--click/--drag/--probe` 坐标 = ChartView 局部**（从 probe columns 的 x/w + contentsH 推算），
  勿 mapFromItem、勿混窗口像素（2026-09 多次定位偏移根因）。
- **hitTest/laneAtX 列边界用 `[left, right)`**（共点归右列）——否则 x==右列 left==左列 right
  时误归左列（拖拽目标错列）。
- **删除/移动后按需刷新 lint**：单删走 sessionCmd 自带 refreshLint；批删（deleteSelection）走
  dispatchCmd 不刷新视图/lint，须手动 `chartSession.refresh()` + `refreshLint()`。
- **`sample_kind_arg` 必须支持 bpm/stop**（builtins.cpp）：定义表数值编辑（sample.setValue/delete）
  依赖它；曾只认 wav/bmp → kind=bpm/stop 时**抛错**，前端定义区「改了没成功、只乐观显示」
  （2026-09 实测，CLI 全链路复现）。任何「定义表数值」新命令先过它。
- **共享 id 语义**（2026-09 用户确认）：**编辑 ref 绑定事件的值 = 改该 `#BPMxx/#STOPxx`
  定义值**，所有引用者同步——BMS 中 ch08/ch09 行只引用定义、无独立数值。实现 =
  `PutTimingCommand` 传播定义值给所有 ref 绑定事件（invert 恢复；**传播循环必须跳过被替换
  事件**——它由 m_old_value 恢复，否则 undo 后值错）；`timing.list` 读侧对 ref 事件按定义值
  输出；写回 ref 值与定义不一致 → **另派生新 id 解耦**（不污染共享引用者）。
- **QML 隐式宽纪律**：`Label` 的隐式宽 = **单行文本宽**（`WordWrap`/`Elide` **都不缩减**）、
  `BbSpinBox` implicitWidth=72、`TextField` 同样偏大——放在 SplitView/StackLayout/窄容器里会
  **撑宽整个 dock**（并挤压同 StackLayout 其它页 + 让对话框内容越界）。长文本/输入项一律显式
  `Layout.minimumWidth`（Label 可 0，SpinBox/TextField 给 36-70），显示侧由 Elide/Wrap 处理。
- **模态 Dialog 右对齐窗口**：把 Popup 放在面板内 `anchors.centerIn` 会随面板（dock）宽度溢出；
  应 `x: (parent.width - width - 12)`、`y: 垂直居中`——模态 Popup 的 parent = **Overlay（窗口），
  与 dock 宽无关**（2026-09 用户「无论 dock 什么宽度都能显示」）。
- **LNTYPE 与放置模式**：LNTYPE 只决定 **LN 放置模式**（LNTYPE 2 = 头尾状态机放普通通道 +
  #LNOBJ 尾；LNTYPE 1 = kind="ln" 直接放 51-69 LN 通道）；**ln_pair 连线对两种模式同时生效**
  （51-69 件恒按 LNTYPE 1 交替配对 + 普通通道 #LNOBJ 件按 LNTYPE 2 head-stack 配对，在
  `rebuild_ln_pairs` 与 `bms_parser` 两侧一致）。放置卡没反应时先看 LN 工具提示的
  `〔LNTYPE?〕` 与 `chartSession.lnType()`（读 chart.meta["LNTYPE"]）。
- **未绑定 WAV 槽位允许放置**（LNOBJ 空音尾）：`ChartSession::sampleValueOf` **不查定义表**
  （仅 id==0 无效）——曾要求定义表存在导致无法放 LNOBJ 尾；lint 负责报「未定义/未绑定引用」
  警告（#LNOBJ id 豁免）。
