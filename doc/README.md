# BeAtBench 文档地图（按需读取）

> **目的**：让新会话/协作者只读当前任务需要的文档，不整包通读。
> **判据（决定 `doc/` 还是 `local/doc/`）**：能被「非本项目参与者」独立理解并用来工作 → **`doc/`**（提交进仓库）；
> 只有越过会话背景才看得懂 / 一过时就没用 / 是待拍板讨论或已被取代的草稿 → **`local/doc/`**（gitignore，永不提交）。
> **`local/` 为本机私人笔记、样本谱面与工具生成物；仓库内不得依赖、不得提交。**
> **新会话第一步读根 `AGENTS.md`（落点约定：文件放哪/去哪找）。**
> **doc/04 是简版现状手册**；开发历史/踩坑/防回退细节（与开发会话强耦合）在 `local/doc/04-开发手册-完整版.md`（gitignore）。

## 3. 文件分布约定（doc vs local/doc）——防误放

> **唯一判据**：① 能被「非本项目参与者」独立理解并用来工作 → `doc/`；② 只有越过会话背景才看得懂 /
> 一过时就没用 / 是待拍板讨论或已被取代的草稿 → `local/doc/`。

| 类别 | 去向 | 例 |
|---|---|---|
| 权威/现状/规格/设计稿/事实参考 | **`doc/`**（提交） | 02 核心模型、04 手册、05 界面、06 协议、08 皮肤、09 动作注册、BMS 笔记 |
| 项目门面 | **`doc/`**（提交） | 根 `README.md`、`CHANGELOG.md` |
| 开发历史/踩坑/防回退 | **`local/doc/`** | `04-开发手册-完整版.md` |
| 老里程碑计划/进度流水 | **`local/doc/`** | `07-M2开发准备计划.md` |
| 已被取代的草稿/定案讨论 | **`local/doc/`** | `01-调研`、`02-对齐稿v0.4-历史`、`03-技术栈对比`、`10-主题与皮肤路线`、`11-L2皮肤布局` |
| 实现快照/审查记录/待办 | **`local/doc/`** | `09-操作注册设计-实现快照`、`12.1/12.3`、`13-*`、`tech-debt` |
| 工具生成物/截图/样本素材 | **`local/`**（子目录） | `archify/`、`screenshot/`、样本谱面、音频 |
| 文档配图（提交进仓库） | **`doc/assets/`** | BMS 笔记的编辑器/游戏截图 |

> **防再犯纪律**：写完临时笔记/进度/踩坑/报告后，先按判据归位；**只有「交接对象」才往 `doc/` 写**。
> 若不确定放哪，先放 `local/doc/` 并标注待升格。

## 4. 建议读取顺序

1. `doc/04-开发手册.md`（引导）；
2. 按上表查当前任务对应的文档；
3. 模型/命令/切音 → `doc/02`；协议 → `doc/06`；GUI/皮肤 → `doc/08`；动作/快捷键 → `doc/09`；
4. **不要整包通读** 05 / BMS 笔记（按需查阅）。
