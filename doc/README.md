# BeAtBench 文档地图（按需读取）

> **目的**：让新会话/协作者只读当前任务需要的文档，不整包通读。
> 新会话第一步读根 `AGENTS.md`（落点与维护约定），再按本表取用。

## 1. 文档分布（`doc/`，全部提交）

| 路径 | 内容 | 什么时候读 |
|---|---|---|
| `doc/04-开发手册.md` | **新会话引导（简版）**：仓库布局、构建命令、代码约定、当前状态、里程碑速览 | 每个新会话必读 |
| `doc/02-核心模型与调用架构.md` | **模型/架构权威**：格式无关模型、命令即接口、切音工作台设计、note 移动机制（§4） | 设计细节 / 编辑命令 / 切音 / 格式扩展 |
| `doc/06-插件体系与时间单位设计.md` | **命令 JSON 协议正式规格**（§3）、插件三层漏斗（摘要）、时间单位与换算边界 | 命令 / 协议 / 插件 / 时序 |
| `doc/07-M7项目化工作流设计.md` | **M7 设计**：文件夹即项目（多谱面导入/会话/对比/批量/打包）、`project.*` 命令、验收与开放问题 | 做 M7 / 项目化 / 多谱面相关工作 |
| `doc/08-QML技术选型与皮肤系统设计.md` | GUI 栈决策、分层皮肤系统（L1/L2/L3）、core↔QML 桥接、surface 清单（§3.6） | 界面 / 皮肤 / 外观 |
| `doc/09-操作注册设计.md` | UI 动作注册表：id 命名、元数据、C++ API、皮肤/扩展衔接、实现状态（§11） | 动作注册 / 快捷键 / 皮肤触发 |
| `doc/10-开发工作流.md` | 开发工作流权威：分支模型、日常门禁脚本、tag→发布放行、备份 | 提交前门禁 / 发版 / 分支流程 |
| `doc/11-打包与发布.md` | 打包/发布权威：package.yml 流水线、deb/rpm/arch 与 Windows 产物、安装布局、发布流程 | 打包 / 发布 / 发行版安装 |
| `doc/05-前端界面设计构思.md` | 页面式信息架构、区域设计、界面↔命令映射、设计 token、术语约定 | 做 `app/` 界面相关工作 |
| `doc/BMS文件分析笔记.md` | BMS 格式逆向笔记（头部/定义/主数据/通道/长音/随机） | 做 BMS codec、格式细节 |
| `doc/pending/` | 挂账台账：待裁决 / 未复现 / 未验证观察项，出口条件必备，解决即删 | 排查未决事项 / 动相关代码前 |
| `README.md`（根） | 项目门面：功能、状态、构建、文档导航 | 介绍项目 / 快速上手 |

## 3. 文件落点判据（doc / pending / 代码注释）

> 完整落点规则与维护纪律见根 `AGENTS.md` §3、§4。速查：

| 内容 | 去向 |
|---|---|
| 权威规格 / 设计 / 交接文档（非项目参与者可独立理解） | **`doc/`**（提交） |
| 项目门面 | **根 `README.md`** |
| 待裁决 / 未复现 / 未验证观察项 | **`doc/pending/`**（提交，出口条件必备，解决即删） |
| 实现细节（交互门控、参数语义、状态流转） | **代码实现处头注释**（文档不双写） |
| 临时截图 / 渲染输出 / 调试日志 | **`local/`**（gitignore，永不提交） |

## 4. 建议读取顺序

1. `doc/04-开发手册.md`（引导）；
2. 按上表查当前任务对应的文档；
3. 模型/命令/切音 → `doc/02`；协议 → `doc/06`；GUI/皮肤 → `doc/08`；动作/快捷键 → `doc/09`；
4. **不要整包通读** 05 / BMS 笔记（按需查阅）。
