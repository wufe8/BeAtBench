## 3. 文件分布约定（doc vs local）

- `doc/`：设计文档与手册，**提交进仓库**，所有会话可见。
- `local/`：私人笔记、样本谱面、**工具生成物**（gitignore，永不提交）。
- 生成物规则：工具生成的中间产物、报告、图一律放 `local/` 子目录（当前：`local/archify/`，含架构图 HTML 与规格 JSON）；只有需要长期共享的文档才考虑提交进 `doc/`。
- 会话内不得假设 `local/` 对协作者存在；引用它只在本地备注中使用。

## 4. 建议读取顺序

1. `doc/04-开发手册.md`（引导）；
2. 按上表查当前任务对应的文档；
3. 需要设计细节时翻 `doc/02` 对应章节；
4. **不要整包通读** 01 / 03 / 05（它们是背景与草案，非当前事实）。
